# Brand concepts

Three title-treatment directions rendered on OpenArt (Nano Banana Pro, text2image, 16:9, 1K). They are direction for a vector logo, not final artwork. Full reasoning in `docs/opening-sequence.md` section 3.

| File | historyId | Direction | Notes |
|---|---|---|---|
| `logo-concept-a.png` | `owqLjRryHeHcSsq9pBgX` | Gold two-line wordmark, coin O, kangaroo-tail S, main street behind | Recommended. Both puns landed. Coin O reads as a coin, tail curls from the S. |
| `logo-concept-b.png` | `YpOIKcSvNnHvsw8Z67Av` | Cream letters with olive outline held in a glowing pouch | The pouch rendered as a gold sack rather than a kangaroo pouch. Lettering treatment is worth keeping for dark backgrounds. |
| `logo-concept-c.png` | `zoky2H77U1gEKvqLhIa3` | Sky-blue arched capitals, three tails as a picket fence, coin sun | Clean and distinctive. Blue letters lose the gold-means-savings link, so better as an alternate. |
